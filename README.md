## About

One line about a meeting that should have been an email, and nothing else.
The meeting ends exactly the way it began — with someone saying "per my
last email", the very email the meeting was supposed to replace.

The entry program (`main.ts`) writes the single line to `/output/entry.txt`:

> The meeting ended the way it began: with someone saying 'per my last email' — the email this meeting was supposed to replace.

One line, 125 characters, under the 200-character limit.

## Run

```sh
node main.ts
```

Deterministic, no network: it always writes the same 125-character line to `/output/entry.txt`.
